## 🇬🇧 English

This repository contains an end-to-end Machine Learning classification pipeline built on the famous [Titanic Dataset from Kaggle](https://www.kaggle.com/datasets/yasserh/titanic-dataset/data). The project covers data preprocessing, missing value imputation, categorical encoding, feature scaling, iterative hyperparameter tuning, and comprehensive performance evaluation across multiple classification models.

### 📊 Dataset & Preprocessing
The dataset is dynamically fetched using `kagglehub`.
* **Feature Selection:** Irrelevant columns (`PassengerId`, `Name`, `Ticket`, `Cabin`) were dropped.
* **Missing Value Imputation:** Missing `Age` values were filled using the **training set median** to prevent data leakage.
* **Categorical Encoding:** Categorical features were converted using One-Hot Encoding (`pd.get_dummies` with `drop_first=True`).
* **Feature Scaling:** `StandardScaler` was applied specifically for distance-based models (KNN and SVM).

### 🤖 Models & Hyperparameter Tuning
The pipeline trains and optimizes five core classification models through iterative loops:
1. **K-Nearest Neighbors (KNN):** Tuned over neighbor sizes ($n = 1$ to $10$).
2. **Decision Tree Classifier:** Multi-step iterative tuning optimizing `max_depth`, `min_samples_split`, and `min_samples_leaf`.
3. **Random Forest Classifier:** Tuned over `n_estimators` and `max_depth`.
4. **Support Vector Machine (SVM):** Optimized regularization parameter `C` ($0.1, 1, 10$) using the non-linear `rbf` kernel.
5. **Naive Bayes (GaussianNB):** Implemented as a probabilistic baseline model.

## 🇹🇷 Türkçe

Bu repo, Kaggle'ın ünlü [Titanic Veri Seti](https://www.kaggle.com/datasets/yasserh/titanic-dataset/data) üzerinde oluşturulmuş uçtan uca bir Makine Öğrenmesi sınıflandırma boru hattını (pipeline) içermektedir. Proje; veri ön işleme, eksik veri doldurma, kategorik verileri kodlama, özellik ölçeklendirme, yinelemeli hiperparametre optimizasyonu ve çoklu sınıflandırma algoritmalarıyla performans değerlendirmesini kapsamaktadır.

### 📊 Veri Seti ve Ön İşleme
Veri seti `kagglehub` kullanılarak dinamik olarak indirilmiştir.
* **Özellik Seçimi:** Analiz için gereksiz veya yüksek kardinaliteli sütunlar (`PassengerId`, `Name`, `Ticket`, `Cabin`) çıkarılmıştır.
* **Eksik Veri Doldurma:** Eksik `Age` değerleri, veri sızıntısını önlemek amacıyla **eğitim setinin medyan değeri** ile doldurulmuştur.
* **Kategorik Kodlama:** Kategorik özellikler One-Hot Encoding (`pd.get_dummies` ve `drop_first=True`) kullanılarak sayısal forma dönüştürülmüştür.
* **Özellik Ölçeklendirme:** Özellikle mesafe tabanlı modeller (KNN ve SVM) için `StandardScaler` uygulanmıştır.

### 🤖 Modeller ve Hiperparametre Optimizasyonu
Proje, iteratif döngüler aracılığıyla beş temel sınıflandırma modelini eğitmekte ve optimize etmektedir:
1. **K-En Yakın Komşu (KNN):** Komşu boyutlarına göre optimize edilmiştir ($n = 1$ ila $10$).
2. **Karar Ağacı (Decision Tree Classifier):** `max_depth`, `min_samples_split` ve `min_samples_leaf` parametreleri aşamalı olarak optimize edilmiştir.
3. **Rastgele Orman (Random Forest Classifier):** `n_estimators` ve `max_depth` değerlerine göre ayarlanmıştır.
4. **Destek Vektör Makineleri (SVM):** Doğrusal olmayan `rbf` çekirdeği (kernel) kullanılarak düzenlulaştırma parametresi `C` ($0.1, 1, 10$) optimize edilmiştir.
5. **Naive Bayes (GaussianNB):** Olasılıksal temel (baseline) modeli olarak eklenmiştir.
